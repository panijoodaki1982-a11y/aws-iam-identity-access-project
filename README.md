# aws-iam-identity-access-project
AWS IAM project demonstrating users groups roles and access control
## Project Overview

This project demonstrates how AWS Identity and Access Management (IAM) works in a real AWS environment.

The configuration includes:

- IAM Users
- IAM Groups
- IAM Roles
- Permission management

## Architecture

The project includes the following components:

- Admin user group
- Multiple IAM users
- IAM roles with EC2 access
- Secure AWS account configuration with MFA
